Norme sulla privacy

Applicazione: Diete Gruppo Sanguigno (com.nutrizione.grupposanguigno)

Ultimo aggiornamento: 23 settembre 2026

Contatto del titolare: paolettag@gmail.com

1. Dati personali raccolti

L'applicazione NON raccoglie, memorizza né trasmette alcun dato personale degli utenti. Non sono presenti account, moduli di registrazione, sistemi di tracciamento, analytics o pubblicità.

2. Contenuti scaricati

L'applicazione scarica esclusivamente file di contenuto pubblico (informazioni sulle diete per gruppo sanguigno e ricette) da un repository GitHub pubblico e li salva nella memoria locale del dispositivo. Tali file non contengono dati personali.

3. Permessi utilizzati

  • Accesso a Internet: utilizzato solo per scaricare e aggiornare i file di contenuto (diete e ricette).
  • Archiviazione locale: utilizzata solo per salvare i file di contenuto scaricati sul dispositivo.

4. Condivisione con terze parti

Nessun dato viene condiviso, venduto o trasmesso a terze parti.

5. Sicurezza

Tutti i contenuti risiedono localmente sul dispositivo dell'utente. Non esistono server proprietari che memorizzano informazioni.

6. Contatti

Per qualsiasi domanda riguardante queste norme sulla privacy, scrivere a: paolettag@gmail.com
